# 🧠 Flash Cards App – Learn French Fast 🇫🇷
---

## ✅ Features

- 📚 Displays French-English word pairs using a CSV file
- 🕒 Shows French word first, then reveals the English translation after 3 seconds
- ❌ Remove words you’ve learned from the list (they won’t appear again)
- 🎴 Simple card-flip interface with images
- 🔁 Randomized word selection for each round

---

## 📦 Requirements

- Python 3.x
- Standard libraries: `tkinter`, `csv`, `random`
- Image assets:
  - `card_front.png` – for the card background
  - `right.png` – button to keep the word
  - `wrong.png` – button to remove the word

---

## 🚀 How to Run

1. Clone the repo or download the script and assets.
